# Deming_Phosphorus
Analysis and figures for project relating to phosphorus cycling in Deming Lake and ferruginous systems

Datasets and corresponding files are located in Zenodo DOI: 10.5281/zenodo.21953894

* Regression_Figure1.R consists of the code used for data analysis and plots relating to Figure 1. 
* Figure2_panels.R consists of the code used for data analysis and plots relating to Figure 2.
* Figure3_panels.R consists of the code used for data analysis and plots relating to Figure 3.
